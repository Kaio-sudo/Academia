

# Fit Control

**Fit Control** é uma aplicação web desenvolvida como projeto acadêmico da disciplina de Engenharia de Software, na Faculdade SENAC, sob orientação do professor Rubens.

O sistema tem como proposta oferecer um painel de controle para academias, reunindo funcionalidades que auxiliam na organização, no gerenciamento e no acompanhamento das atividades administrativas, proporcionando uma experiência mais prática e intuitiva.

## Objetivo do Projeto

Desenvolver uma aplicação web que simule um sistema de gerenciamento de academia, aplicando conceitos de Engenharia de Software, organização de interfaces, desenvolvimento web e estruturação de funcionalidades voltadas à administração de um ambiente fitness.

## Tecnologias Utilizadas

- **HTML5** — Estruturação das páginas e dos elementos da aplicação.
- **CSS3** — Estilização, layout e responsividade da interface.
- **GitHub** — hospedagem do site.
